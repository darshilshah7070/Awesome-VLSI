# Contributing to Awesome VLSI

Thank you for your interest in contributing to the Awesome VLSI list! This document provides guidelines to ensure quality and consistency in our curated collection.

## How to Contribute

### Before You Start
- Check if the resource is already listed
- Ensure the resource is related to VLSI, chip design, or verification
- Verify the resource is accessible and of good quality

### Adding a Resource

1. **Fork the repository** and create a new branch
2. **Locate the appropriate section** (or create a new subsection if needed)
3. **Add your entry** in alphabetical order within the section
4. **Follow the format**: `- [Resource Name](URL) - Brief description`
5. **Provide a clear description** (one-liner that explains what it is)

### Example Addition

```markdown
## Some Section

- [Existing Tool](https://example.com/) - Does something useful
- [My New Tool](https://example.com/new) - Does something even better
- [Another Tool](https://example.com/other) - Does other things
```

## Submission Guidelines


### Format Requirements

- **Title**: Clear, concise name (no ALL CAPS unless abbreviation)
- **URL**: Working link with HTTPS
- **Description**: 5-15 words explaining the resource's value
- **Placement**: Logical section with similar resources

### Adding New Sections

If you want to add a new section:

1. Choose a descriptive name
2. Add to the **Contents** table at the top (maintain alphabetical order)
3. Create the section with at least 3 high-quality entries
4. Use consistent formatting with existing sections


## Reporting Issues

Found a broken link or outdated information? Please:

1. Open an issue with the title: `[BROKEN] Resource name`
2. Provide the link and why it's broken
3. Suggest a replacement if available


## Questions?

- Create an issue for discussions
- Use clear, descriptive titles
- Reference relevant sections

Thank you for helping make Awesome VLSI better! 🎉
